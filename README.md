# Bakery Website (SASS Project)

A stylish and responsive bakery website built using HTML and Sass (SCSS). This project showcases my skills in organizing styles, utilizing Sass features (variables, nesting), and structuring a clean and responsive layout.

##  Tech Stack

- HTML5
- Sass (SCSS)
- CSS (compiled from SCSS)
- Vercel (for deployment)

##  Features

- Elegant bakery-themed UI design.
- Built with Sass to improve maintainability and modularity.
- Fully responsive across devices.
- Automatically compiled CSS from Sass.
- Deployed and live for demonstration.
